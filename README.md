This repository contains all of my **Algorithm Lab assignments and implementations** completed during my undergraduate studies. Each lab focuses on different algorithmic techniques including sorting, greedy methods, graph algorithms, dynamic programming, and more.

The purpose of this repository is to practice problem-solving skills and understand the implementation of fundamental algorithms using **C++**.
